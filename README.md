# MwiDrive

**Problem:** Motorcycle taxi riders in Kenya lack tools to manage orders efficiently. Passengers without internet or digital literacy can't reliably book rides.

**Solution:** USSD-first ordering system for offline-first motorcycle taxis. Riders get a mobile admin app. Passengers use USSD (dial code → menu) to order.

**Who:** Motorcycle sacco owners, riders, passengers in areas with low internet/digital literacy.


## Tech Stack
